# 2026-08-20 — 定義は5艦にあった。足りなかったのはコピーされる場所の印だった

> **対象期間**: 08-19 深夜（hub の店じまい後に新しい玉が発令されて再開）〜 08-20 未明。**1セッション**につき連番なし。

> **hub の店じまい宣言をセッション境界として扱った**（粒度規約・hub 裁定 2026-08-05 / #241）。

前セッションを締めた直後に、hub から**金額単位の正典を6艦へ配る**玉が来た。艦隊は `*_cents` の意味で
**3対3 に割れており**（円 1:1 = invoice / vault / profile ／ 1/100円 = clear / deal / serve）、
指示は「**是正より先に、正典を書く場所を作れ**」だった。

配り終えてみると、**当初の見立ては3回とも現物と食い違っていた**。①正典だけをコードのコメントに書くと、
**コードが違反している艦ではコメントが嘘になる**。②「×100 の例がある」だけでは直すべきか決まらない——
**決めるのはその艦のコードがどちらか**で、serve では**直すほうが嘘になる**。③そもそも
**正しい定義を持っていた艦は6艦中5艦**あった。**「定義が無かったから間違えた」艦は実質ゼロだった。**

**残ったのは、定義の有無ではなく「実装者が定義を読んだか、コードをコピーしたか」という違いだけだった。**
serve の `format-money.ts` は deal と冒頭6行が完全一致で、**逸脱はコードのコピーで伝播していた**。
⇒ **順序0 の価値の中心は「定義を足すこと」ではなく「コピーされる場所に印を置くこと」へ移った。**
