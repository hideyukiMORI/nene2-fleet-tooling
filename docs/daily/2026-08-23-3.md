### 5. `Button` の中の svg（#355 / **PR #358 マージ済み**・0.11.0）

width/height 属性も CSS 寸法も無い `<svg>` は**置換要素の既定 300×150**まで広がる。

🔴 **`max-*` であって `size-*` ではない。** 任意バリアント `[&_svg]:` は**子孫セレクタ**へ落ちるので `Icon` の素のクラス（`h-5 w-5`）より**詳細度が高く**、`size-*` を当てると **`<Icon size="sm">` がボタン側の寸法で描かれる**。

🔑 **この区別が消えると退行は目視でしか出ない**ので、`[&_svg]:(size|h|w)-` を**禁止するテスト**で固定した。
