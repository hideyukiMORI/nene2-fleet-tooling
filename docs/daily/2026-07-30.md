## 今日いちばんの学び

**「存在を機能の証拠として読まない」** — 一夜で6層の標本が出た。

| 層 | 断絶 |
| --- | --- |
| 供給 | 台帳に登録した → 供給されない（#159） |
| 検査 | 台帳に登録した → 検査されない（#176） |
| 更新 | 下げても記録できない（#176 → #181） |
| 参照 | 「差異登録なき」と言う → 差異登録を読まない（#184） |
| 配布 | 実装した → publish されていないので艦で使えない |
| 配線 | 依存にある・import している → canonical が効いていない（records） |

共通の根因は **「登録経路のテストはあっても、登録が効くことの負テストが無い」**。以後、検査器を足すときは陽性対照（故意に壊して FAIL することの確認）を必ず同梱する＝**1回効かせて観測してから通す**。

そして #184 を止められたのは、**deal が「この理解で合っていますか」と聞いてくれて、その一言で実装を開いたから**だった。文言は実装の要約であって約束ではない。**聞かれなければ私も踏んでいた。**
