## 🔴 知らないと踏む制約

### 凍結

**新文書・新条文・新検査器の追加は「批准前提(c) 緑 → 契約v1凍結成立」後の最初の patch 波まで凍結**（hub 裁定）。新文書追加が checker の `--docs` 対象と `mustTotal` を動かし、**すでに GREEN の批准前提(a) を再オープンしかねない**ため。

**例外（実績4件）**: 既存検査器の**欠陥修正＝bug-fix 相当は凍結対象外**（#159 / #176 / #178 / #184 とも同じ理路で通した）。パッケージ実装も対象外。挙動変更を伴うものは minor bump 同乗が筋で、**`MUST 総数 248` 不変を実測してから**出す。

### マージ・publish のゲート

- **マージ・npm publish は施主（hide）承認後**（CLAUDE.md）。**hub の裁定はこれを上書きできない**——2026-07-30 に hub が「検査器 PR は hub 受入で足りる」と裁定したが差し戻し、hub が「hub の誤りだった」と撤回した。
- **「出してよい」（内容受入＝hub 管轄）と「入れてよい」（マージ実行＝リポの明文ゲート）は別のゲート**。
- **中継された GO は実行権限ではない**。施主本人の確認を取る。
- **publish の実行者は施主**（`docs/publish.md` 明文）。担当リナは準備と検証まで。ローカル `npm publish` は `publishConfig.provenance: true` により**構造的に不可**（Trusted Publishing の CI からのみ）。**設定を緩めて通さない。**

### stacked PR

**base の retarget を、依存元 PR のマージより前に行う。** `--delete-branch` で head を消すと stacked 側が CLOSED になり reopen できない（issues#54・フリートで2回既出）。#180 → #181 で実際に回避した。

## 指揮系統と作法

**fleet は統合リナ（hub）の指揮下**（施主指示 2026-07-29）。依頼が来たら対応・**疑問は詳細な理由をつけて hub へ**・施主判断が要るものだけ施主へ。**作業完了ごとに hub へ完了報告＋確認依頼＋レビュー依頼**を relay で送る。

### 今夜効いた作法（続ける）

- **他艦の報告は鵜呑みにせず fleet で再現してから issue 化する**（#176 で deal の 29行超過より強い20倍超過の陽性対照を自前で作れた）。
- **負の対照を取る** — 修正を stash してテストが落ちることを確認する。「テストが通った」を「テストが欠陥を検出できる」の証拠にしない。
- **帰属を先に宣言すると相手が検算してくれる**（#172 で「原文から変えた6箇所」を先に表にしたので records が全数検算し、**必須修正1件**が出た）。
- **他艦から仕様を聞かれたら、推測でなく実装を読んでから答える**（#184 は deal の「この理解で合っていますか」で実装を開いて発覚した。**文言は実装の要約であって約束ではない**）。
- **「実装済み」を「使える」と書かない** — merge と publish が間に挟まる。
- relay 相手が落ちていたら即 handoff ファイル方式へ切替＋関連 issue にその旨コメント。

## 通底する教訓 — 「存在を機能の証拠として読まない」

2026-07-30 の一夜で**7層の標本**が出た。`_work/advice.md` に収載済み・凍結明けの 06 章 運用則候補。

| 層 | 断絶 |
| --- | --- |
| 供給 | 台帳に登録した → 供給されない（#159） |
| 検査 | 台帳に登録した → 検査されない（#176） |
| 更新 | 下げても記録できない（#176 → #181） |
| 参照 | 「差異登録なき」と言う → 差異登録を読まない（#184） |
| 配布 | 実装した → publish されていないので艦で使えない |
| 配線 | 依存にある・import している → canonical が効いていない（records） |
| 導入 | 導入済み3艦が green → **新規導入が通る証拠ではない**（#189） |

共通根因は **「登録経路のテストはあっても、登録が効くことの負テストが無い」**。検査器を足すときは**陽性対照**（故意に壊して FAIL することの確認）を必ず同梱する＝**1回効かせて観測してから通す**。
