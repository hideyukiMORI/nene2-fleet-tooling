## 測るときの作法（今日3回踏んだ）

計器を信じる前に**測り方**を確かめること。以下はすべて 2026-07-30 に実地で踏んだ:

1. **依存が入った checkout で測る。** `npm install` 未実行の checkout で conformance を回すと
   `unknown(not-installed)` になり、**艦の欠陥と区別がつかない**（#194 で分類を分けた）。
2. **cwd は `src/**`を持つディレクトリ。** リポ直下から測ると「適用ファイル数 0」で unknown に落ちる
（フロントが`frontend/` にある艦で起きる・#194 の details に測り直し手順を入れた）。
3. **class を数えるときは境界を付ける。** 素の `grep '\btext-primary\b'` は `text-text-primary` を
   拾う（`\b` は `-` を境界扱いする）。#98 でこれを踏み、境界つきで測り直して 0 を確認した。
4. **不在の証明に不適な道具を使わない。** `gh pr view <n>` は issue を解決しないので、
   その出力は「存在しない」の根拠にならない（#464 で踏んだ）。
5. **検査器の文言を pin しない。** テストは「実効 N < canonical M」の**形**で判定する。
   文言 pin は #185（文言是正）との組み合わせで落ちた（＝#184 の教訓が自分のテストにも効いた）。
